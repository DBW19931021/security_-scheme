# 抗注入攻击库

## 功能说明

对外提供硬件抗注入攻击的功能，具体提供以下防护机制：

* 随机延时，需要外部提供熵源，需要外部实现fid_delay_get_random接口
* 双变量，变量被重定义为两个成员的结构体，其中一个为原值，另一个是一异或值
* 全局故障循环，错误时可调用此循环，采用多重循环跳转以增加反解循环的难度
* 控制流程完整性，使用全局变量在关键流程中记录变化，避免被跳过

## 如何使用

* 顶层cmake文件引用fid.cmake文件
* 顶层cmake文件需要定义FID_LEVEL
  * FID_LEVEL为0代表不开启任何防护机制
  * FID_LEVEL为1代表开启低等级防护（开启"控制流完整"、"全局故障循环"，“双变量”）
  * FID_LEVEL为2代表开启高等级防护机制，在低等级防护基础上开启“随机延时”
* 如果开启高等级防护，需要用户实现接口fid_delay_get_random
* 如果用户需要处理panic（例如记录、上报）则需要实现函数fid_panic_callback
