# SRC-0028 安全测试表格格式参考入库报告

## 入库结果

- 原样保存用户提供的最终表截图并登记SHA-256。
- 只读审阅参考工程Mailbox和Spinlock的README、功能/逻辑说明、冻结Case、13列CSV和最终XLSX。
- 转录13列表头、视觉样式、输入/输出/通过准则粒度和形成流程。

## 可进入本轮交付的内容

- 安全测试最终表改用与参考工程一致的13列和连续编号。
- 每条输入改为可执行步骤；输出改为实际采集项；通过准则明确PASS/FAIL/INCONCLUSIVE。
- 形成可独立阅读的SoC安全架构、功能与Case说明文档。

## 不得继承的内容

- Mailbox/Spinlock的IP地址、寄存器、复位、中断、测试值和Expected。
- 参考工程的实现布局或旧平台假设。
- 任何能够反向改变安全方案DUT边界、用例数量或EDA分工的推论。
